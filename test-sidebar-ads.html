🧪 Test - Sidebar Ads & Monetag Integration

✅ Checklist de Verificación

  • ✓ Sidebars cargados a izquierda y derecha
  • ✓ Scripts de sidebar-ads.js inicializados
  • ✓ Monetag native banners configurados
  • Verifica en consola (F12) que no haya errores
  • Abre DevTools → Console para ver logs

📋 Información de Debugging

Abre la consola del navegador (F12) y busca:

✅ Sidebar ads inicializados 📢 Monetag zone 8655548 cargando en sidebar-left-ad 📢 Monetag zone 8655550 cargando en sidebar-right-ad

🔍 Si los ads NO aparecen:

  1. Verifica en DevTools que los elementos DOM existan:
    document.querySelector('.sidebar-ad-left') // Debe existir document.getElementById('sidebar-left-ad') // Debe existir
  2. Verifica que Monetag zones están correctas:
    • Zone 8655548 = Sidebar izquierdo
    • Zone 8655550 = Sidebar derecho
  3. Verifica que sidebar-ads.js cargó correctamente:
    console.log(window.SidebarAds) // Debe mostrar objeto con métodos
  4. Verifica que los scripts de Monetag se cargaron:
    // En Network tab, busca requests a www.topcreativeformat.com

💡 Posibles Soluciones

  • Zone IDs incorrectos: Verifica en tu panel de Monetag
  • Bloqueo de ads: Desactiva ad blockers en esta página
  • Región no permitida: Monetag puede no servir en algunas regiones
  • Cuenta Monetag no aprobada: Los ads solo aparecen con cuenta verificada
